# Tabvia

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md) | [日本語](./README.ja.md) | **한국어** | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md)

Tabvia는 브라우저의 새 탭 페이지를 대체하는 북마크 관리 도구입니다. 현재 확장 프로그램 버전은 **0.2.5**입니다. [변경 기록](./CHANGELOG.md)을 확인하세요.

링크를 로컬에 저장하고 그룹으로 정리하며, JSON 백업을 가져오거나 내보낼 수 있습니다. 원한다면 직접 관리하는 외부 저장소로 데이터 스냅샷을 동기화할 수 있습니다. 로컬 우선 구조로, 로그인이나 자체 백엔드가 필요하지 않습니다. UI는 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어, 프랑스어, 독일어를 지원합니다.

이 저장소는 pnpm workspace를 사용합니다. 제품 코드는 `apps/extension`의 Manifest V3 확장 프로그램입니다. Tabvia 북마크는 브라우저에 내장된 북마크바와 별도로 관리됩니다.

- 소스 코드: [miss55/happy-tab](https://github.com/miss55/happy-tab)
- 문제 보고: [GitHub Issues](https://github.com/miss55/happy-tab/issues)
- 개인정보 처리방침: [공개 페이지](https://miss55.github.io/happy-tab/privacy-policy.html)

## 저장소 구조

- `apps/extension`: Vite, Vue 3, TypeScript로 만든 Chrome MV3 확장 프로그램.
- `docs`: 제품 및 아키텍처 문서.

## 개발

저장소 루트에서 실행하세요.

```sh
# 의존성 설치
pnpm install
# 개발 서버 실행
pnpm dev:extension
# 확장 프로그램 매니페스트 검사
pnpm check:manifest
# 프런트엔드 테스트 실행
pnpm test
# 확장 프로그램 빌드 (TypeScript 검사 포함)
pnpm build:extension
```

Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켜고, 압축 해제된 확장 프로그램으로 `apps/extension/dist`를 로드한 뒤 새 탭을 여세요.

Chrome Web Store와 Microsoft Edge Add-ons용 패키지 준비는 [스토어 등록 문서](./docs/store-listing.md), 스토어에서 요구하는 개인정보 처리방침은 [관련 문서](./docs/privacy-policy.md)를 확인하세요. GitHub Pages의 게시 위치를 `main` 브랜치의 `docs/`로 설정한 후, 두 스토어 관리 화면에 `https://miss55.github.io/happy-tab/privacy-policy.html`을 등록할 수 있습니다.

## 현재 기능

로컬 새 탭 MVP와 선택적 외부 클라우드 스냅샷 동기화를 구현했습니다.

- Chrome 새 탭 페이지를 대체하며, 같은 패키지를 Microsoft Edge에서도 사용할 수 있습니다.
- 현재 열린 브라우저 탭을 창별로 표시하고, 탭 전환과 닫기를 지원합니다.
- 링크 그룹, 저장한 링크, 할 일을 IndexedDB에 보관하며, 저장소 계층과 Dexie를 통해 데이터를 읽고 씁니다.
- 링크 그룹 생성, 이름 변경, 삭제, 드래그 정렬을 지원합니다.
- 북마크 페이지로 그룹을 정리합니다. 페이지 생성, 이름 변경, 순서 변경, 빈 페이지 삭제를 지원하며, 편집 화면에서 그룹이나 링크를 다른 페이지로 옮길 수 있습니다. 빠른 탐색, 브라우저 탭, 선택적으로 표시하는 할 일 목록은 모든 페이지에서 공유합니다.
- 버튼을 누르거나 브라우저 탭을 링크 그룹으로 드래그해 링크로 저장할 수 있습니다. URL을 직접 입력해 추가할 수도 있습니다.
- 저장한 링크를 새 탭으로 열며, 열기 횟수와 마지막으로 연 시각을 기록합니다.
- 그룹 안이나 그룹 사이에서 저장한 링크를 드래그해 정렬할 수 있습니다.
- 할 일 생성, 완료·미완료 전환, 편집, 삭제, 드래그 정렬을 지원합니다. 할 일 목록은 기본적으로 숨겨져 있으며 가져오기/내보내기 화면에서 켤 수 있습니다.
- 8개 언어의 UI를 제공하며 브라우저 언어를 자동으로 감지합니다. 수동으로 선택한 언어는 로컬에 저장합니다.
- 버전이 있는 JSON 백업을 내보내고, 검증 후 병합 또는 교체 방식으로 가져옵니다. 북마크 페이지, 그룹, 링크, 할 일, 사용 통계, 빠른 탐색이 포함됩니다. 백업 형식 v2는 페이지 소속을 보존하며 v1도 가져올 수 있습니다.
- Soft, Minimal, Glass, Fluent, OLED, Cyber 테마와 밝게·어둡게·시스템 모드, 강조색, 기본 배경 이미지, 로컬 사용자 지정 배경을 지원합니다. 앱이 로드되기 전에 저장된 모양을 적용합니다.
- 북마크 위에 빠른 탐색 바를 제공합니다. URL 입력 또는 브라우저 탭·저장한 링크 드래그로 바로가기를 추가하고 정렬, 편집, 삭제할 수 있습니다. 현재 페이지 세션 안에서 삭제를 취소할 수 있습니다.
- 링크 그룹을 메이슨리 레이아웃으로 배치하고 제목에 파스텔 색을 자동으로 지정합니다. 색은 그룹별로 바꿀 수 있습니다.
- 직접 관리하는 Upstash Redis, GitHub Gist, Cloudflare KV, JSONBin 또는 사용자 지정 REST 엔드포인트로 선택적으로 동기화합니다. 스냅샷에는 북마크 페이지와 빠른 탐색도 포함됩니다.

여러 북마크 페이지를 사용하기 전에 동기화하는 모든 기기를 업데이트하세요. 이전 클라이언트는 페이지 목록을 보존할 수 없습니다. 마이그레이션, 백업, 동기화 호환성은 [북마크 페이지 문서](./docs/bookmark-pages.md)를 확인하세요.

추가 개선 또는 검증이 필요한 항목:

- 기존 단위 테스트와 페이지·테마 브라우저 검사 외의 자동화 범위 확대.
- Chrome과 Edge에서 압축 해제된 확장 프로그램의 전체 회귀 테스트.

브라우저 기본 북마크 동기화는 현재 개발 범위에 포함되지 않습니다.
