# Tabvia

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md) | **日本語** | [한국어](./README.ko.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md)

Tabvia は、ブラウザーの新しいタブページを置き換えるブックマーク管理ツールです。拡張機能の現在のバージョンは **0.2.5** です。[変更履歴](./CHANGELOG.md)をご覧ください。

リンクをローカルに保存してグループ分けし、JSON バックアップをインポート・エクスポートできます。必要に応じて、自分が管理する外部ストレージにスナップショットを同期することもできます。ローカル優先の設計で、ログインも専用バックエンドも不要です。UI は英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、フランス語、ドイツ語に対応しています。

このリポジトリは pnpm workspace です。製品本体は `apps/extension` にある Manifest V3 拡張機能です。Tabvia のブックマークは、ブラウザー標準のブックマークバーとは独立しています。

- ソースコード：[miss55/happy-tab](https://github.com/miss55/happy-tab)
- 問題の報告：[GitHub Issues](https://github.com/miss55/happy-tab/issues)
- プライバシーポリシー：[公開ページ](https://miss55.github.io/happy-tab/privacy-policy.html)

## リポジトリ構成

- `apps/extension`：Vite、Vue 3、TypeScript で開発した Chrome MV3 拡張機能。
- `docs`：製品とアーキテクチャのドキュメント。

## 開発

リポジトリのルートで実行します。

```sh
# 依存関係をインストール
pnpm install
# 開発サーバーを起動
pnpm dev:extension
# マニフェストを検証
pnpm check:manifest
# フロントエンドのテストを実行
pnpm test
# 拡張機能をビルド（TypeScript チェックを含む）
pnpm build:extension
```

Chrome の `chrome://extensions` または Edge の `edge://extensions` で開発者モードを有効にし、展開済みの拡張機能として `apps/extension/dist` を読み込んで、新しいタブを開きます。

Chrome Web Store と Microsoft Edge Add-ons 向けのパッケージ作成は[ストア掲載ガイド](./docs/store-listing.md)、ストアで必要なプライバシーポリシーは[ポリシーのドキュメント](./docs/privacy-policy.md)をご覧ください。GitHub Pages の公開元を `main` ブランチの `docs/` に設定した後、両ストアの管理画面に `https://miss55.github.io/happy-tab/privacy-policy.html` を登録できます。

## 現在の機能

ローカルの新しいタブページ MVP と、任意の外部クラウドストレージへのスナップショット同期を実装しています。

- Chrome の新しいタブページを置き換えます。同じパッケージを Microsoft Edge でも使用できます。
- 開いているブラウザータブをウィンドウごとに表示し、切り替えや閉じる操作ができます。
- リンクグループ、保存したリンク、ToDo を IndexedDB に保存し、リポジトリ層と Dexie を通じてデータを読み書きします。
- リンクグループの作成、名前変更、削除、ドラッグによる並べ替えができます。
- ブックマークページでグループを整理できます。ページの作成、名前変更、並べ替え、空ページの削除に対応し、編集画面からグループやリンクを別のページに移動できます。クイックナビ、ブラウザータブ、任意表示の ToDo リストは全ページで共通です。
- ボタン操作やグループへのドラッグでブラウザータブをリンクとして保存できます。URL を手入力して追加することもできます。
- 保存したリンクを新しいタブで開き、開いた回数と最終日時を記録します。
- 同じグループ内やグループ間で、保存したリンクをドラッグして並べ替えられます。
- ToDo の作成、完了・未完了の切り替え、編集、削除、ドラッグによる並べ替えができます。ToDo リストは初期状態では非表示で、インポート／エクスポート画面から有効にできます。
- 8 言語の UI を提供し、ブラウザーの言語を自動判定します。手動で選択した言語はローカルに保存します。
- バージョン付き JSON バックアップの出力と、検証済みデータのマージ・置換インポートに対応しています。対象はブックマークページ、グループ、リンク、ToDo、利用統計、クイックナビです。バックアップ形式 v2 はページの所属を保持し、v1 も読み込めます。
- Soft、Minimal、Glass、Fluent、OLED、Cyber のテーマ、ライト・ダーク・システム連動、アクセントカラー、同梱壁紙、ローカルのカスタム背景に対応しています。保存した外観をアプリの読み込み前に適用します。
- ブックマークの上にクイックナビを配置します。URL の入力やブラウザータブ・保存したリンクのドラッグで追加でき、並べ替え、編集、削除、現在のページセッション内での削除の取り消しに対応しています。
- リンクグループをメイソンリーレイアウトで表示し、見出しのパステルカラーを自動で割り当てます。色はグループごとに変更できます。
- 自分が管理する Upstash Redis、GitHub Gist、Cloudflare KV、JSONBin、カスタム REST エンドポイントへの任意の同期に対応しています。スナップショットにはブックマークページとクイックナビも含まれます。

複数のブックマークページを使う前に、同期するすべての端末を更新してください。古いクライアントはページの一覧を保持できません。移行、バックアップ、同期の互換性は[ブックマークページの説明](./docs/bookmark-pages.md)をご覧ください。

今後の改善・検証項目：

- 既存の単体テストとページ・テーマのブラウザーチェックに加え、自動テストの対象を拡大すること。
- Chrome と Edge で、展開済み拡張機能の完全な回帰テストを行うこと。

ブラウザー標準のブックマーク同期は、現在の開発範囲に含まれません。
